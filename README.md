# Epic Flail

**RU.** Сборки игры Epic Flail для Windows.
Как установить: скачай **[Install_EpicFlail.bat](https://github.com/Archiefx/EpicFlail-Releases/releases/latest/download/Install_EpicFlail.bat)**, запусти его, впиши папку для игры (или просто нажми Enter) и подожди. Установщик сам скачает самую свежую версию, распакует её и сделает ярлык на рабочем столе. Чтобы обновить игру — запусти его ещё раз и укажи ту же папку.

**PL.** Wersje gry Epic Flail dla Windows.
Instalacja: pobierz **[Install_EpicFlail.bat](https://github.com/Archiefx/EpicFlail-Releases/releases/latest/download/Install_EpicFlail.bat)**, uruchom go, wpisz folder gry (albo po prostu naciśnij Enter) i poczekaj. Instalator sam pobierze najnowszą wersję, rozpakuje ją i utworzy skrót na pulpicie. Aby zaktualizować grę — uruchom go ponownie i wskaż ten sam folder.

**EN.** Windows builds of Epic Flail.
To install: download **[Install_EpicFlail.bat](https://github.com/Archiefx/EpicFlail-Releases/releases/latest/download/Install_EpicFlail.bat)**, run it, type the game folder (or just press Enter) and wait. It downloads the newest version, unpacks it and puts a shortcut on the desktop. To update, run it again with the same folder.

Requirements / Требования / Wymagania: Windows 10/11 64-bit, DirectX 12 GPU (Shader Model 6).

**If the game asks for "Microsoft Visual C++ 2015-2022 Redistributable (x64)"** / **Если игра просит Visual C++** / **Jeśli gra prosi o Visual C++**:
[vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe) (Microsoft) — install, then start the game again / установи и запусти игру снова / zainstaluj i uruchom grę ponownie. The installer above does it by itself.
